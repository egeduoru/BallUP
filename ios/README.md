# БаллUP для iPhone

Автономная оболочка WKWebView с заданиями внутри приложения. Сайт и интернет для тренировки не требуются. Иконка предоставлена владельцем проекта.

## Сборка

На macOS с Xcode: `bash ios/build.sh` из корня репозитория. GitHub Actions выполняет ту же команду на стандартном macOS runner. Результат: `ios/dist/BallUP-1.0.0.ipa`.

IPA подписан временной ad-hoc подписью для последующей переподписи через AltStore Classic. Сам по себе такой IPA не устанавливается обычным открытием в приложении «Файлы». Apple Account и сертификаты не передаются GitHub Actions.

## Установка и продление

1. Установить AltServer на Windows по https://faq.altstore.io/altstore-classic/how-to-install-altstore-windows . Документация перечисляет необходимые версии iTunes/iCloud.
2. Подключить разблокированный iPhone по USB и подтвердить доверие компьютеру.
3. Через меню AltServer установить AltStore на iPhone. Ввести данные Apple Account непосредственно в AltServer, не в чат и не в репозиторий.
4. На iPhone подтвердить доверие разработчику и включить режим разработчика по запросу системы.
5. Передать IPA на iPhone. В AltStore: My Apps → + → выбрать IPA.
6. Включить фоновое обновление AltStore, Wi-Fi-синхронизацию и держать AltServer доступным. До истечения семи дней проверять My Apps → Refresh All. Автоматическое обновление может не сработать, если компьютер выключен или iOS не разрешила фоновый запуск.

Продление подписи не требует новой версии приложения. Не удаляйте БаллUP для обычного продления: удаление может стереть локальный прогресс.

## Проверка на телефоне

После установки проверить запуск без сети, ввод ответа с клавиатуры, возврат, сохранение после закрытия и повторного открытия, поворот экрана, оба режима задания6. До этих проверок сборка не считается проверенной на реальном iPhone.
